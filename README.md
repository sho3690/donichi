# 土日 DONICHI

Instagram・Threads・X・TikTok などで見つけた「行きたい所」のリンクをみんなでストックすると、
キャプションや説明欄から日付・場所・営業時間などを読み取ってまとめ、
**毎週木曜の朝7時に、今週末（土日＋つながった祝日）の予定として自動で割り振る**アプリです。

- 公開先: https://sho3690.github.io/donichi/
- 使えるのは、合言葉か招待リンクを持っている人だけです。

## しくみ

```
[スマホ/PC のブラウザ]
   │ リンクを追加・行った・入れ替え など（合言葉で暗号化してから送る）
   ▼
[中継 ntfy.sh]  ← 登録不要。暗号文だけを約12時間あずかる。他の人の画面にもすぐ届く
   │ 15分ごとに取り込む
   ▼
[GitHub Actions  scripts/sync.mjs]
   ・Instagram / Threads / TikTok / X / YouTube / 一般サイトから投稿の本文を取る
   ・本文から日付・期間・場所・営業時間・定休日・料金・種類を読み取る（ルール。Claude の鍵があれば別の手順で Claude）
   ・期間の過ぎたものを片づける
   ・木曜7時を過ぎたら、天気予報（Open-Meteo）・期限・行きたい人の数・エリアのまとまりを見て週末に割り振る
   ・暗号化して data/state.json に保存 → GitHub Pages で配信
```

- **暗号化**: 合言葉 → PBKDF2(SHA-256, 21万回) → AES-256-GCM。リポジトリは公開ですが、
  `data/state.json` と中継のメッセージは暗号文なので、合言葉が無いと中身は読めません。
  GitHub の無料プランでは非公開リポジトリから Pages を出せないため、この形にしています。
- **招待リンク**（`#k=…`）は鍵そのものを URL の `#` 以降に入れたものです。`#` 以降はサーバーに送られません。
  信頼できる人にだけ送ってください。招待するときは、受け取ったリンクをそのまま転送するか、設定で合言葉を入れて作り直します。
- **端末の中の鍵**: 開いたあとは「取り出せない形（non-extractable）」の鍵だけを IndexedDB に置き、親鍵そのものは保存しません。
  sho3690.github.io は他のアプリと同じ置き場なので、万一そちらに不正なスクリプトが入っても鍵を持ち出されないようにするためです
  （その場で使われることまでは防げません。気になる場合は独自ドメインへの移設が根本策です）。
- **Actions の守り**: Claude Code（外部パッケージ・版を固定）は**別のジョブ（別のマシン）**で動かし、そこにはデータの鍵も
  書き込み権限も渡しません。本文と結果は受け渡し専用の鍵 `AI_KEY`（Secrets に登録済み）で封をして渡します。
  同期の結果は Claude より先に保存します。GitHub への書き込み権限は push の手順だけで使い、外部の Action はコミットの番号で固定しています。
- 投稿の取得は、接続するその瞬間に相手の IP を確かめ、社内・クラウド内部向けの宛先には接続しません。
- **Actions のログは公開**されるので、件数以外（題名・URL・名前）は出力しないようにしています。
- **15分ごとに動かすしくみ**: 新しいリポジトリでは GitHub の定時実行が一度も起動しないことがあるため、
  各回が「15分待ってから次の回を予約する」ようにしています（環境 `interval` の待ち時間。待つ間はマシンを使いません）。
  定時実行は途切れたときの予備（1時間ごと）です。
  止めるとき: `gh workflow disable auto-sync.yml -R sho3690/donichi`
  / 再開するとき: `gh workflow enable auto-sync.yml -R sho3690/donichi && gh workflow run auto-sync.yml -R sho3690/donichi`
- TikTok / X / YouTube は、追加したその場でブラウザから本文を取ります（公式の oEmbed。X は予備に fxtwitter）。

## 割り振りのルール（logic.js の planWeekend）

- 対象: ストックにあり、その日に行けるもの（期間内・定休日でない・平日限定でない・期限切れでない）
- 1日の上限: 設定の「予定の量」（ゆったり1件 / ふつう2件 / たっぷり3件）。「1日」かかる遠出はその日を占める
- 点数: 単日開催 +60、期限が近い +12〜45、行きたい人が多い +12/人、ストックして長い +最大15、前回見送り +8/回、
  雨の日の屋外 −60・屋内 +12、晴れの日の屋外 +14、同じエリアをまとめて回れる +12、同じ種類が重なる −15
- 時間帯: 午前 10:00 / 午後 14:00 / 夜 18:30（投稿の内容から向いている時間を推定）
- 画面から「入れ替え」「外す」「ストックから選ぶ」「割り振り直す」ができます

## Claude で読み取りを賢くする（任意）

最初はルールだけで読み取ります。Claude を使うと、要約（「かんたんに言うと」）や店名・期間の読み取りが良くなります。
ほかの自動化（一日一頁・生成AI新聞）と同じ長期トークンを、ターミナルで次の1行で登録してください:

```
gh secret set CLAUDE_CODE_OAUTH_TOKEN -R sho3690/donichi < ~/.config/claude-headless/oauth_token
```

登録後は 15 分ごとの同期で、まだ読み取っていないものから順に Claude（道具なし・本文はデータとして扱う）が読み取ります。

## 合言葉を変える（招待リンクが広まりすぎたとき）

```
node scripts/setup.mjs --keep-state       # データはそのまま、新しい合言葉で封し直す
gh secret set DONICHI_KEY -R sho3690/donichi < .secrets/master.b64
git add config.json data/state.json && git commit -m "合言葉を変更" && git push
```

新しい合言葉・招待リンクは `.secrets/owner.txt` に出ます（コミットされません）。古いリンクでは開けなくなります。

## 開発

```
npm test                         # 計算・暗号・本文の解析のテスト（node --test）
python3 -m http.server 8790      # http://127.0.0.1:8790/ で画面を確認
```

ファイル: `index.html` / `style.css` / `app.js`（画面） · `logic.js`（日付・祝日・読み取り・割り振り・データ更新の純粋関数）
· `crypto.js`（暗号） · `relay.js`（中継） · `sources.js`（本文の取得と解析）
· `scripts/sync.mjs`（同期・割り振り） · `scripts/ai.mjs` / `ai-merge.mjs`（Claude の読み取りと反映） · `scripts/setup.mjs`（合言葉の作成・変更）

木曜の割り振りの試運転（時刻を差し替えて、一時コピーで実行）:
```
DONICHI_KEY="$(cat .secrets/master.b64)" DONICHI_NOW=$(node -e "console.log(Date.parse('2026-10-29T07:05:00+09:00'))") node scripts/sync.mjs
```
